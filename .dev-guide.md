# Development Environment Guide

This guide explains the improved development setup for the portfolio project.

## Available Commands

### Quick Start Commands
```bash
# Start all services (Vite, Storybook, Docs, Server)
yarn dev:all

# Start only frontend services (Vite + Storybook)
yarn dev:frontend

# Start minimal setup (Vite + Server)
yarn dev:minimal

# Enhanced development with better process management
yarn dev:enhanced

# Show help and available options
yarn dev:help
```

### Individual Services
```bash
# Vite development server (React app)
yarn dev                    # → http://localhost:5173

# Storybook component documentation  
yarn storybook              # → http://localhost:6006

# Jekyll documentation site
yarn dev:docs              # → http://localhost:4000

# Express production server
yarn serve                  # → http://localhost:3001
```

## Service Information

| Service   | Port | URL                       | Description                    |
|-----------|------|---------------------------|--------------------------------|
| Vite      | 5173 | http://localhost:5173     | React development server       |
| Storybook | 6006 | http://localhost:6006     | Component documentation        |
| Docs      | 4000 | http://localhost:4000     | Jekyll documentation site      |
| Server    | 3001 | http://localhost:3001     | Express production server      |

## Features

### Color-Coded Output
Each service has its own color for easy identification:
- **Vite**: Cyan
- **Storybook**: Magenta  
- **Docs**: Yellow
- **Server**: Green

### Process Management
- **Graceful Shutdown**: Ctrl+C properly stops all services
- **Auto-restart**: Services automatically restart on failure (up to 3 tries)
- **Clean Prefix**: Each log line is prefixed with `[service-name]`
- **Timestamps**: Optional timestamps for debugging

### Service Combinations
- **all**: All four services (full development environment)
- **frontend**: Just Vite + Storybook (frontend development)
- **minimal**: Just Vite + Server (basic development)

## Configuration

The development environment is configured in `/dev.config.js`. You can:
- Modify service colors and names
- Change port numbers
- Add new service combinations
- Customize startup patterns

## Troubleshooting

### Port Conflicts
If you get port conflicts, the services will show which ports are in use:
- Vite: Check if port 5173 is available
- Storybook: Check if port 6006 is available  
- Docs: Check if port 4000 is available
- Server: Check if port 3001 is available

### Service Won't Start
1. Check if dependencies are installed: `yarn install`
2. For docs: Ensure Ruby and Jekyll are installed
3. Check the specific service logs for error details

### Clean Shutdown Issues
If services don't shut down cleanly:
1. Use Ctrl+C to send SIGTERM
2. Wait up to 5 seconds for graceful shutdown
3. Services will be force-killed if needed

## Advanced Usage

### Custom Service Combinations
Edit `dev.config.js` to add new combinations:
```javascript
combinations: {
  mysetup: ['vite', 'server'], // Custom combination
  // ... other combinations
}
```

Then use: `yarn dev:enhanced mysetup`

### Environment Variables
Services respect environment variables:
- `PORT`: Override server port (default: 3001)
- `NODE_ENV`: Set environment mode
- `ALLOWED_DOMAINS`: Configure CORS domains
